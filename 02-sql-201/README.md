# SQL 201

SQL 201 will focus on analytical querying.

At this level, the goal is to move from basic commands to business questions:

- Which customers generated the most revenue?
- Which products are losing demand?
- Which cities have the highest order volume?
- How do different tables connect through keys?

## Planned Topics

| Order | Topic | Query Family |
| --- | --- | --- |
| 01 | Filtering and conditional queries | DQL |
| 02 | Aggregate functions | DQL |
| 03 | `GROUP BY` and `HAVING` | DQL |
| 04 | Joins | DQL |
| 05 | Subqueries | DQL |
| 06 | Views for reusable analysis | DDL + DQL |

## Learning Note

At this stage, SQL starts to feel less like syntax and more like thinking with tables. The important part is not memorizing every clause, but understanding the question behind the query.
