# SQL 301

SQL 301 will focus on T-SQL programming and reusable database logic.

This level is useful when repeated manual queries are no longer enough and the database needs controlled logic.

## Planned Topics

| Order | Topic | Purpose |
| --- | --- | --- |
| 01 | Variables | Store temporary values |
| 02 | `IF` / `ELSE` | Build decision logic |
| 03 | Loops | Repeat controlled operations |
| 04 | Stored procedures | Package reusable workflows |
| 05 | User-defined functions | Return reusable calculations |
| 06 | Triggers | React to table events carefully |
| 07 | Window functions | Analyze rows with context |

## Learning Note

T-SQL programming should be used with discipline. Logic inside the database can be powerful, but too much hidden logic can make systems hard to debug.
