# SQL 401

SQL 401 will focus on production-level SQL thinking.

At this level, the main question is not only whether a query works, but whether it is safe, maintainable, and performant.

## Planned Topics

| Order | Topic | Focus |
| --- | --- | --- |
| 01 | Indexing fundamentals | Query performance |
| 02 | Execution plans | Understanding how SQL Server runs a query |
| 03 | Transactions and locking | Data consistency |
| 04 | Security and permissions | DCL in real systems |
| 05 | Backup and recovery basics | Operational safety |
| 06 | Query optimization | Better performance with less cost |

## Learning Note

Production SQL requires careful habits. A query that works on 100 rows may become expensive on 100 million rows. This level is where performance, safety, and design start to matter together.
