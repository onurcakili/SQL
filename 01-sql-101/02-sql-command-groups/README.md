# SQL Command Groups

This folder separates SQL commands by their responsibility.

Instead of learning SQL as a long command list, think about intent:
## Files

| File | Focus |
| --- | --- |
| `00-full-sql-command-reference.sql` | Original full command reference |
| `01-ddl-data-definition-language.sql` | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` |
| `02-dml-data-manipulation-language.sql` | `INSERT`, `UPDATE`, `DELETE` |
| `03-dql-data-query-language.sql` | `SELECT`, filters, aggregates, grouping, joins |
| `04-dcl-data-control-language.sql` | `GRANT`, `REVOKE`, `DENY` |
| `05-tcl-transaction-control-language.sql` | `BEGIN TRANSACTION`, `COMMIT`, `ROLLBACK` |
