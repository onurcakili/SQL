# Database Setup

This folder contains sample database scripts used by the SQL 101 lessons.

Run these scripts before the command examples if your local SQL Server environment does not already have the required sample tables.

## Files

| File | Purpose |
| --- | --- |
| `01-sql-server-sample-database.sql` | General SQL Server sample database setup |
| `02-etrade-sample-database.sql` | E-Trade sample database setup |

## Note

Database setup scripts can create or modify database objects. Read the comments before running them.
