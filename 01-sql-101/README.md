# SQL 101

SQL 101 introduces databases, SQL Server basics, data types, and core command families.

The goal is to understand what SQL commands do before writing complex queries. This level answers questions like:

- What is a database?
- Why do data types matter?
- What is the difference between DDL, DML, DQL, DCL, and TCL?
- Why can an unsafe `DELETE` or `UPDATE` damage real data?

## Suggested Flow

1. Read the introduction file.
2. Study data types before creating tables.
3. Use DDL to create database objects.
4. Use DML carefully to change data.
5. Use DQL to query and analyze data.
6. Learn DCL and TCL as safety topics, not as optional extras.
